    Mechanical design · MVP prototype

    Weighing food where it is stored.

    Smart Clip is a hanging load-cell experiment for a fridge inventory concept. The user identifies the food; the sensing system tracks its weight.

    The current MVP isolates one question before adding an enclosure, battery, display, or cloud connection: can a suspended load produce a repeatable measurement on a real fixture?

    A working baseline

    The earlier 1 kg bench prototype was calibrated with a 50.0 g reference and returned a 49.4 g check reading. BLE also sent readings to a browser.

    02

    A capacity change

    The revision uses a 10 kg hanging cell so the sensor can carry a practical food load without approaching the original 1 kg limit.

    03

    A connection problem

    Fine sensor leads did not survive improvised breadboard and solder connections. The response is an HX711-mounted screw terminal plus strain relief.
